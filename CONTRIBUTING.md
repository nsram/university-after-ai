# Contributing

Thanks for helping improve this presentation.

## Content corrections

Please open an issue with:

- slide number
- current wording
- proposed correction
- source or rationale, where relevant

## Display problems

Please include:

- device and browser
- portrait or landscape orientation
- slide number
- screenshot if possible

## Style

Keep slides concise and readable at presentation distance. Prefer concrete examples over dense exposition. Avoid adding dependencies unless they materially improve the presentation.
